Gust — an iOS port of Breezy Weather
====================================

This application is a port of Breezy Weather 6.2.2 to iOS. It is an independent
project, not affiliated with or endorsed by the Breezy Weather authors.

Not included:
  No Breezy Weather artwork, fonts or signing keys are redistributed. The app icon
  is original to this project. The name "Breezy Weather" is used only to describe
  what this software is a port of, never as a product name.

Boundaries:
  The port implements a subset of the upstream feature set. Features that depend on
  Android-only platform services (live wallpaper, RemoteViews widgets, boot
  receivers, foreground services, cross-app icon packs) are intentionally absent.
